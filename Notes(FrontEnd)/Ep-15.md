# Deployment on AWS

- Signup on AWS
- Launch Instance
- chmod 400 <secret>.pem  (basically sets file permissions so that only the file’s owner can read it)
- connected to our aws instance/machine using ssh -i "devTinder-secret.pem" ubuntu@ec2-15-206-174-105.ap-south-1.
  compute.amazonaws.com
- To logout from maching/instance write 'exit' 
- Install Node version 20.19.0 (same as ur local one)
- Git clone of our Frontend/Backend repos
* for Frontend ->
  - cd GitTogether
  - npm install -> install all the dependencies
  - npm run build
  - sudo apt update (to update our ubuntu system)
  - sudo apt install nginx (HTTP Server)
  - sudo systemctl start nginx (to start nginx)
  - sudo systemctl enable nginx
  - Copy code from dist.(build files) to /var/www/html/ (ngnix http server repository)
  - sudo scp -r dist/* /var/www/html/  (sudo-to get root level permissions, scp-copy, -r mean recursively, dist/*
                                         means all folders of dist)
  - Enable port :80 of your instance (as http web server of nginx is deployed on port no 80)


* for Backend ->
  - npm run dev is used for development 
  - npm run start is used for production
  - First we need to allow access of our MongoDB to the aws instance(just paste ip address of instance in mongoDB
    network access)
  - Similarly enable port :7777 of ur instance
  - Now we cannot keep the server open 24/7 using npm start on terminal hence use PM2 to keep our application
    online 24/7   
  - npm i pm2 -g
  - pm2 start npm --name "devtinder-backend" -- start
  - If some issues comes during above command,u can use 'pm2 logs' to see
  - pm2 list, pm2 flush <name>, pm2 stop <name>, pm2 delete <name>


  Frontend = http://15.206.174.105/
  Backend = http://15.206.174.105:7777/

  Domain name = devtinder.com => 15.206.174.105

  Frontend = devtinder.com
  Backend = devtinder.com:7777 => devtinder.com/api         (we will map port 7777 to /api using nginx proxy pass,)
  

  - config nginx - sudo nano /etc/nginx/sites-available/default             (nano->to edit the file, )
  - nginx config : 

    server_name 15.206.174.105

    //Proxy /api requests to Node.js (comment)
    location /api/ {
        proxy_pass http://127.0.0.1:7777/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
  - restart nginx - sudo systemctl restart nginx

  - Lastly, change ur BASE_URL in frontend from localhost:7777 to "/api" , it will automatically go to our
    instance's IP+port no
